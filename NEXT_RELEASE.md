# Notes for the next production release

Add one line per change, starting with "- " (players read these in the
update log). Publishing to production turns them into the new version's notes
in scripts/Savia.gd and empties this list.
- Leaderboards: Quest is now just VR (the VR choice has every VR and Quest play), and Spectate shows Quest players as VR

- Menu Customizer: every button, dropdown, preset button and heading in the menu now follows your colours (new colour for the pink headings and highlights)
- Your level and prestige now sync between devices signed in to the same account: the device with the higher level/prestige sets the others to the same
