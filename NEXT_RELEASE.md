# Notes for the next production release

Add one line per change, starting with "- " (players read these in the
update log). Publishing to production turns them into the new version's notes
in scripts/Savia.gd and empties this list.
- Test builds no longer install themselves for tester accounts: you get the Update / Remind me in a day / Later box like everyone else
- New Cursor Bloom setting (World & Cursor): real bloom on just the cursor (and its trail if you want), with size, strength, colour and a pulse on hits
- Spectate: the search box is the same height as the favourites heart
- Happy Halloween: on 31 October the menu waves turn orange and purple, with bats and embers (Settings > Replays & Misc > Seasonal Themes turns it off)
- Chat while spectating: the global chat sits in the bottom-left corner while you watch someone; press Enter (or click it) to type
- Spectating: the player's glow, bloom and cursor bloom show even if you use Sound Space Mode (it follows their setting while you watch)
- The custom speed box can be clicked and typed in again
